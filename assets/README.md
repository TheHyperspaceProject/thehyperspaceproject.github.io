# THP Asset Layout

Every gameplay asset is modular.

Examples:

- `games/FactoryPanic/assets/machines/<machine>.js`
- `games/FactoryPanic/assets/machines/<machine>.css`
- `games/Crossfall/assets/characters/<character>.js`
- `games/Crossfall/assets/characters/<character>.css`
- `games/RIFT/assets/models/<model>.js`
- `games/RIFT/assets/models/<model>.css`
- `games/RIFT/assets/weapons/<weapon>.js`
- `games/RIFT/assets/weapons/<weapon>.css`

This keeps presentation and behavior isolated per asset instead of putting every character/model into one giant stylesheet or script.
